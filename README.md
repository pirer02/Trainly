**Trainly** es una aplicación móvil diseñada para la gestión, planificación y seguimiento personalizado de entrenamientos deportivos. A través de una interfaz intuitiva con vista de calendario, permite llevar un control estricto de las rutinas diarias y el progreso a lo largo del tiempo.

## ✨ Características Principales
* **Planificación por Calendario:** Organización visual y dinámica de los entrenamientos programados para cada día de la semana.
* **Seguimiento a Medida:** Registro detallado de ejercicios, series, repeticiones y pesos adaptados a las necesidades del usuario.
* **Persistencia en la Nube:** Almacenamiento seguro e inmediato del historial de entrenamiento y perfiles de usuario utilizando Firebase.

## 🛠️ Tecnologías Utilizadas
* **Lenguaje de Programación:** Java
* **Base de Datos y Autenticación:** Firebase (Cloud Firestore / Realtime Database y Firebase Auth)
* **Entorno de Desarrollo:** Android Studio / Java SE *(Modifica según corresponda)*
